# Firebase Setup Guide for Radius

## Prerequisites

1. **Firebase Account**: Create a project at [Firebase Console](https://console.firebase.google.com/)
2. **FlutterFire CLI**: Install for automatic configuration

## Step 1: Install FlutterFire CLI

```bash
dart pub global activate flutterfire_cli
```

## Step 2: Configure Firebase

Run from your project root:

```bash
flutterfire configure
```

This will:
- Create a Firebase project (or select existing)
- Register Android and iOS apps
- Generate `lib/core/config/firebase_options.dart` with your credentials

## Step 3: Android Configuration

### 3.1 Update `android/build.gradle`

```gradle
buildscript {
    dependencies {
        // Add this line
        classpath 'com.google.gms:google-services:4.4.0'
    }
}
```

### 3.2 Update `android/app/build.gradle`

```gradle
plugins {
    id 'com.android.application'
    id 'kotlin-android'
    id 'dev.flutter.flutter-gradle-plugin'
    id 'com.google.gms.google-services'  // Add this line
}

android {
    // ...
    defaultConfig {
        // Minimum SDK for Firebase Auth
        minSdkVersion 23
    }
}
```

### 3.3 Google Sign-In (Android)

1. Go to Firebase Console > Authentication > Sign-in method
2. Enable **Google** provider
3. Add your SHA-1 fingerprint:

```bash
# Debug SHA-1
cd android
./gradlew signingReport
```

4. Copy the SHA-1 and add it in Firebase Console > Project Settings > Your apps > Android app

## Step 4: iOS Configuration

### 4.1 Update `ios/Podfile`

```ruby
platform :ios, '13.0'  # Minimum iOS version
```

### 4.2 Google Sign-In (iOS)

1. Download `GoogleService-Info.plist` from Firebase Console
2. Add it to `ios/Runner/` using Xcode
3. Add URL scheme to `ios/Runner/Info.plist`:

```xml
<key>CFBundleURLTypes</key>
<array>
    <dict>
        <key>CFBundleTypeRole</key>
        <string>Editor</string>
        <key>CFBundleURLSchemes</key>
        <array>
            <!-- Reversed client ID from GoogleService-Info.plist -->
            <string>com.googleusercontent.apps.YOUR-CLIENT-ID</string>
        </array>
    </dict>
</array>
```

## Step 5: Enable Firebase Services

### Authentication
1. Go to Firebase Console > Authentication
2. Click **Get started**
3. Enable **Email/Password** provider
4. Enable **Google** provider

### Firestore Database
1. Go to Firebase Console > Firestore Database
2. Click **Create database**
3. Start in **test mode** for development
4. Choose a location (cannot be changed later)

### Firestore Security Rules (Development)

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Users collection
    match /users/{userId} {
      allow read: if request.auth != null;
      allow write: if request.auth != null && request.auth.uid == userId;
    }
    
    // Connections collection
    match /connections/{connectionId} {
      allow read: if request.auth != null && 
        request.auth.uid in resource.data.participants;
      allow create: if request.auth != null;
      allow update, delete: if request.auth != null && 
        request.auth.uid in resource.data.participants;
    }
    
    // Proximity logs
    match /proximity_logs/{logId} {
      allow read: if request.auth != null && 
        (request.auth.uid == resource.data.observerUserId || 
         request.auth.uid == resource.data.detectedUserId);
      allow create: if request.auth != null && 
        request.auth.uid == request.resource.data.observerUserId;
    }
  }
}
```

## Step 6: Verify Installation

Run the app:

```bash
flutter run
```

Check the debug console for any Firebase initialization errors.

## Troubleshooting

### Common Issues

1. **"No Firebase App"**: Ensure `Firebase.initializeApp()` is called in `main.dart`

2. **Google Sign-In fails on Android**: 
   - Verify SHA-1 is added in Firebase Console
   - Ensure `google-services.json` is in `android/app/`

3. **Google Sign-In fails on iOS**:
   - Check URL scheme is correctly added
   - Verify `GoogleService-Info.plist` is in the Xcode project

4. **Firestore permission denied**:
   - Check security rules allow the operation
   - Verify user is authenticated

## File Structure After Setup

```

├── app/
│   ├── google-services.json     # Firebase Android config
│   └── build.gradle             # Updated with google-services plugin

ios/
├── Runner/
│   ├── GoogleService-Info.plist # Firebase iOS config
│   └── Info.plist               # Updated with URL scheme

lib/
└── core/
    └── config/
        └── firebase_options.dart # Generated by FlutterFire CLI
```
