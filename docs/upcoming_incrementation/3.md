Extend the existing group chat system to support **location-based random chatrooms** and **location-based help chats**, using **cell-tower or coarse location data** (not precise GPS) to group users by area while maintaining privacy.

---

## Feature Overview

Enable users to automatically access **random chat groups and help chatrooms** based on their **current cell tower or approximate location zone**. These chatrooms allow users in the same area to communicate, seek help, or support each other in real time.

---

## Location Detection Rules

### 1. Location Source

* Use **cell tower ID**, network area code, or coarse location buckets.
* Do NOT use or store precise GPS coordinates.
* Location is updated dynamically as the user moves.

---

## Location-Wise Random Group Chats

### 2. Auto-Mapped Area Groups

* Each location zone automatically maps to:

  * A **Random Chat Group**
  * A **Help Chat Group**
* Example:

  * “Random Chat – Sector 21”
  * “Help Chat – Sector 21”

### 3. Group Visibility

* Users automatically see:

  * Random chat groups for their current location
  * Help chat groups for their current location
* Groups are visible only while the user remains in that location zone.

---

## Chat Access Model

### 4. Open Access

* Users do NOT need to join groups.
* Users can:

  * Open any visible location-based chat
  * Read messages
  * Send messages freely
* Leaving the location automatically removes access.

---

## Help Chats (Safety & Support)

### 5. Location-Based Help Chat

* Dedicated **Help Chat** exists for each location zone.
* Intended for:

  * Emergency assistance
  * Silent help requests
  * Asking for nearby support
* Messages are visible only to users currently in the same location.

### 6. Silent Help Usage

* Users can send:

  * “I need help”
  * “Is anyone nearby?”
  * “Emergency”
* No alarms, calls, or public notifications.
* Optional escalation:

  * Trusted contacts
  * Emergency services (opt-in)

---

## Group Lifecycle

### 7. Auto Expiry

* Groups exist as long as users are present in the location.
* If no active users remain:

  * Group becomes inactive or hidden.
* Old messages may auto-expire (optional).

---

## Privacy & Safety

### 8. Privacy Controls

* No exact location sharing.
* No identity exposure unless user chooses.
* Messages limited to area-based visibility.
* Block and report functionality available.

---

## Integration with Existing Group Types

The app now supports **four group categories**:

1. **Nearby Groups** (Bluetooth + internet, creator-scanned)
2. **Random Groups** (Global, internet-based)
3. **Location-Wise Random Groups** (Cell-tower based)
4. **Location-Wise Help Chats** (Cell-tower based)

Each group type:

* Uses shared chat infrastructure
* Appears in its own discovery section

* Enable local community interaction
* Provide silent, nearby help without GPS tracking
* Increase engagement through contextual chatrooms
* Maintain privacy-first design
