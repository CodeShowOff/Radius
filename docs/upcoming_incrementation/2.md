Design an additional feature that allows users to **create and participate in random group chatrooms** that are not limited by proximity. These chatrooms are designed for open conversation, discovery, and engagement.

---

## Feature Overview

Random Group Chats are **user-created open chatrooms** where any user can freely enter, view conversations, and participate. These groups are discoverable through a dedicated page and do not require invitations, proximity, or approval.

---

## Random Group Creation

### 1. Manual Random Group Creation

* Any user can create a **Random Chat Group**.
* Group properties:

  * Group name
  * Optional topic or category
  * Creator ID
  * Active status

### 2. Group Scope

* These groups are **not location-based**.
* Bluetooth scanning is **not required**.
* Internet-only connectivity.

---

## Random Groups Discovery Page

### 3. Random Groups Page

* Add a dedicated page called **“Random Groups”**.
* The page displays:

  * List of all active random group chats
  * Group name
  * Topic/category
  * Current active participants count (optional)

### 4. Database-Based Listing

* The app fetches all active random groups from the database.
* Groups are shown in real time or near real time.

---

## Chat Access & Participation

### 5. Open Chat Model

* Users can:

  * Open any random group chat.
  * View messages instantly.
  * Send messages without needing approval.
* No explicit “join” requirement.
* Leaving the chat does not affect group existence.

---

## Group Lifecycle

### 6. Group Persistence Rules

* Random groups remain active until:

  * Creator deletes the group, or
  * The group is inactive for a defined time (optional).
* System may auto-archive inactive groups.

---

## Safety & Moderation

### 7. Abuse Prevention

* Block and report options.
* Message rate limiting.
* Creator or system moderation controls.
* Optional content filtering.

---

## Integration with Existing System

### 8. Parallel Group Types

The app now supports:

1. **Nearby Groups** (Bluetooth + internet presence-based)
2. **Random Groups** (Internet-only open chatrooms)

Both group types:

* Use the same chat infrastructure
* Are shown on separate discovery pages

---

## Key Objectives

* Increase engagement through open conversations
* Allow users to socialize beyond proximity
* Create community-style chatrooms
* Keep entry friction minimal

---
